# metropolia-project2
## Sorting Game

Your objective is to sort trash into the correct container before the timer runs out. You will start with 30 seconds and sorting the trash to the correct bin will grant you with more time, but failing to sort it correctly or the trash is not picked up from the line in time, will reduce your time. The game ends when the timer ends and your play time will be saved to the scoreboard. Scoreboard shows the best times by other players. The sustainable development Goal of the game is responsible consumption.
